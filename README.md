# Dfns Api usage examples

> [!WARNING]
> **Deprecated.** These scripts hand-roll authentication and request signing
> against the raw Dfns API and are no longer maintained. For Python, use the
> official **[Dfns Python SDK](https://github.com/dfns/dfns-sdk-python)**, which
> handles authentication, user-action signing, and typed API access for you.

This repo contains example scripts of how Dfns api can be used.
